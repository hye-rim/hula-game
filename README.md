# 훌라 🂡

컴퓨터 세 명(민수·지아·도윤)과 겨루는 혼자 하는 훌라입니다. 서버 없이 `index.html` 만 열면 돌아갑니다. 점수는 게임용입니다.

- 조작: 카드를 눌러 고르고(위로 올라옴) 아래 버튼을 누릅니다. 더미나 버린 카드를 직접 눌러도 됩니다. 키보드: `D` 뽑기, `T` 땡큐, `S` 스톱, `R` 등록, `A` 붙이기, `X` 버리기, `P` 일시정지, `M` 소리. 「정렬」은 무늬순/숫자순을 바꿉니다.
- 규칙과 컴퓨터는 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙 (일반 훌라, 조커 없음)
- 52장, 4명이 7장씩. 남은 카드는 더미이고 한 장을 뒤집어 버린 카드 자리에 놓습니다. 딜러 왼쪽부터 시계 방향.
- 내 차례: ① 더미에서 한 장을 뽑거나 **땡큐** → ② 묶음 **등록**·**붙이기** → ③ 한 장 버리기.
- **묶음**: 같은 숫자 3~4장(무늬는 모두 다르게), 같은 무늬 연속 3장 이상(A 는 A-2-3 또는 Q-K-A, K-A-2 처럼 돌아가는 건 안 됨), **7 은 한 장만으로도** 등록할 수 있고 다른 7 을 붙일 수 있습니다.
- **붙이기**: 한 번이라도 등록한 사람만, 이미 놓인 묶음(남의 것도)에 한 장씩. 같은 숫자는 4장까지, 연속은 양쪽 끝으로.
- **땡큐**: 바로 앞 사람이 버린 카드를 가져오는 것. 가져와서 **바로 등록하거나 붙일 수 있을 때만** 가능하고, 가져온 카드를 먼저 써야 버릴 수 있습니다. 한 차례에 한 번.
- **나감**: 손패를 모두 털면 판이 끝나고, 다른 사람이 남은 손패 점수(A=1 … K=13)를 이긴 사람에게 냅니다. 이번 턴 전까지 한 번도 등록하지 않았는데 한 턴에 모두 털면 **훌라**(점수 ×2).
- **스톱**: 뽑기 전에 내 손패 점수가 15점 이하이면 선언할 수 있습니다. 다른 모두의 점수가 나보다 높으면 성공(차이만큼 받음), 같거나 낮은 사람이 있으면 실패(나머지에게 내 점수 + 10점씩 줌).
- 더미가 바닥나면 판이 끝나고 가장 낮은 사람이 차이만큼 받습니다(동점이면 무승부).
- 5판 승부, 점수 합계가 가장 높은 사람이 우승입니다. 모든 판의 합은 0점입니다.
- **난이도**: 시작할 때 고릅니다. 「쉬움」은 컴퓨터가 땡큐를 40% 놓치고, 등록을 20% 미루고, 30%는 최선이 아닌 카드를 버리며, 8턴 전에는 스톱하지 않고 7점 이하일 때만 스톱합니다. 「보통」은 아래 설명 그대로입니다. 쉬움에서는 최고 기록이 저장되지 않습니다.
- 컴퓨터는 손패에서 겹치지 않게 가장 많이 털 수 있는 묶음을 찾아 등록하고, 붙일 수 있으면 붙이고, 짝이 될 가망이 없는 큰 카드를 버립니다. 점수가 낮아지면 스톱합니다.

## 참고한 것과 확인하지 못한 값
- 훌라는 지역·서비스마다 규칙이 다릅니다. [나무위키 훌라](https://namu.wiki/w/%ED%9B%8C%EB%9D%BC), [위키백과 훌라](https://ko.wikipedia.org/wiki/%ED%9B%8C%EB%9D%BC_(%EC%B9%B4%EB%93%9C_%EA%B2%8C%EC%9E%84)), [나비 게임 가이드](https://board-static.pmang.com/images/pmang/nabi/html/guide/hoolra/hoolra_2_4.html) 등에서 확인한 공통 규칙(7장, 등록·붙이기·땡큐·스톱·훌라, 7 한 장 등록, A 의 높낮이)을 따랐습니다.
- 제가 정한 값(자료마다 달라 확정하지 못함): 점수 환산(A=1 … K=13), 스톱 가능 점수 15점 이하(4인 기준, 나비 가이드의 값), 스톱 실패 벌금(내 점수 + 10점), 훌라 ×2, 5판 승부, 조커 없음, 땡큐 상대 제한(앞 사람 한 명뿐인 일반 규칙을 따름), 컴퓨터의 판단 기준. 하이·로우·7 포카드 같은 미등록 족보와 「7 은 14점」 같은 판본별 규칙은 넣지 않았습니다.
- 온라인 대전은 없습니다. 그림·소리는 직접 그린/합성한 것입니다.
